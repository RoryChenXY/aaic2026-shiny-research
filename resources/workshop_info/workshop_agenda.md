# Workshop Agenda  
## Shiny Your Research: Interactive Dashboards in R  
### AAIC 2026 ISTAART Immersives Workshop

**Format:** Half-day immersive workshop  
**Time:** 1:00 p.m. – 5:00 p.m.  
**Audience:** Dementia researchers, clinicians, analysts, students, and research support staff with basic R experience.

---

# Learning Objectives

By the end of this workshop, participants will be able to:

- Understand the foundational concepts and features of the `{shiny}` package
- Create interactive and dynamic Shiny dashboards through guided coding
- Design reproducible and scalable Shiny workflows
- Apply Shiny to communicate scientific outputs in accessible formats
- Test integration of large language models (LLMs) using `{ellmer}` and `{querychat}`

---

# Detailed Agenda

## 1:00 – 1:30 p.m.  
## Introductions and Scene Setting

### Topics
- Welcome and workshop overview
- Facilitator introductions
- Participant introductions and expectations
- Overview of workshop goals and learning pathway
- Software and environment check
- Repository walkthrough

### Activities
- Confirm R and RStudio setup
- Open workshop GitHub repository
- Load datasets and starter templates

### Key Outcomes
Participants are ready to follow the live coding exercises and understand the overall workshop structure.

---

## 1:30 – 2:00 p.m.  
## Shiny Fundamentals and Real-World Demonstrations

### Topics
- What is Shiny?
- Why use Shiny in dementia research?
- Core app structure:
  - `ui`
  - `server`
  - `shinyApp()`
- Inputs, outputs, and reactivity
- Dashboard design principles
- Reproducibility and accessibility considerations

### Live Demonstrations
- Minimal reactive Shiny app
- Dementias Platform Australia (DPAU) Metadata Explorer demonstration
- Examples of interactive research dashboards


### Key Outcomes
Participants understand the conceptual foundations of Shiny and how interactive dashboards support research communication and exploration.

---

## 2:00 – 3:00 p.m.  
## Guided Coding: Build Your First Shiny Dashboard

### Hands-On Exercise

Participants progressively build a Shiny dashboard using openly available Global Burden of Disease (GBD) Alzheimer's disease and other dementias (ADOD) datasets.

### Step-by-Step Topics
1. Creating a basic Shiny app
2. Adding interactive inputs
3. Building reactive plots and tables
4. Creating multi-tab dashboards
5. Applying basic styling and layout improvements
6. Introducing modular design concepts
7. Optional: Adding LLM-powered features using `{ellmer}` and `{querychat}`

### Teaching Approach
- Live coding
- Guided replication
- Short checkpoint pauses
- Troubleshooting support
- Peer discussion

### Key Outcomes
Participants complete a functional interactive dashboard and gain confidence with core Shiny workflows.

---

## 3:00 – 3:30 p.m.  
## Break

### Optional Activities
- Informal Q&A
- Networking
- Individual troubleshooting support

---

## 3:30 – 4:30 p.m.  
## Independent Dashboard Development

### Independent Exercise

Participants build or extend their own Shiny dashboard using:
- supplied dementia datasets
- or their own data (optional)

### Suggested Project Ideas
- Incidence and prevalence explorer
- Mortality trends dashboard
- Cohort metadata explorer
- Biomarker visualization tool
- Interactive filtering and comparison dashboard

### Facilitator Support
Workshop facilitators circulate to:
- troubleshoot issues
- review app structure
- provide coding support
- discuss deployment and reproducibility

### Extension Opportunities
Advanced participants may explore:
- reactive filtering workflows
- modular app structures
- custom themes with `{bslib}`
- AI-assisted querying workflows

### Key Outcomes
Participants independently apply workshop concepts to a realistic research communication problem.

---

## 4:30 – 5:00 p.m.  
## Group Sharing and Wrap-Up

### Activities
- Small-group dashboard demonstrations
- Participant reflections
- Discussion of implementation challenges and opportunities
- Recommended next steps for continued learning

### Wrap-Up Topics
- Deployment pathways
- Reproducible workflow recommendations
- GitHub and sharing strategies
- Additional Shiny learning resources

### Final Deliverables
Participants leave with:
- reusable Shiny templates
- workshop code examples
- completed exercises
- GitHub repository access
- practical next steps for independent development

---

# Pre-Workshop Requirements

Participants should bring:
- a laptop computer
- R installed
- RStudio installed
- Required packages installed
- basic familiarity with R syntax and scripts

Workshop materials, datasets, and setup instructions will be shared in advance through a dedicated GitHub repository.
